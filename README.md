# Syslog lab: Debian + BulatOS

Параметры: config.json. По умолчанию сервер 10.121.20.39, интерфейс enp0s31f6, UDP/514, пользователь pavel.

## Запуск

```bash
sudo apt install rsyslog tcpdump
cd /home/pavel/Desktop/br9000/syslog-lab
./check.sh
sudo ./start.sh
```

Start проверяет наличие IP на интерфейсе, добавляет пользователя в adm и задаёт права журналов. Создаёт /etc/rsyslog.d/10-gns3.conf. Существующий файл принимает только если узнаёт конфигурацию этого стенда; оригинал сохраняет в /var/lib/syslog-lab/10-gns3.original.conf.

**Каждый start очищает ВСЁ содержимое /var/log/remote**, предварительно сохраняя архив в /var/lib/syslog-lab/archives/. Остальные журналы не очищаются. Для сохранения текущих логов установи clear_logs_on_start в false. archive_before_clear=false отключает архивирование: тогда удаление необратимо. Архивы автоматически не удаляются.

На время очистки лабораторный приёмник отключается; UDP-сообщения в это время могут потеряться. После очистки включается приёмник и автозапуск службы rsyslog. При ошибке скрипт возвращает предыдущую конфигурацию; очищенные файлы восстанавливаются вручную из архива.

После первого запуска выполни в своём терминале newgrp adm или заново войди в сеанс. Тогда чтение и Tab работают без sudo. Группа adm также открывает чтение других системных журналов.

## Остановка и статус

```bash
sudo ./stop.sh
sudo ./status.sh
```

Stop отключает только управляемый лабораторный приёмник и перезапускает rsyslog. Локальные журналы Debian продолжают работать. Логи, архивы, права и членство в adm сохраняются. Приёмник остаётся отключённым после перезагрузки до следующего start. Другие приёмники не отключаются.

## Просмотр

```bash
find /var/log/remote -type f
tail -F /var/log/remote/CP-1/IS-IS.log
sudo tcpdump -ni enp0s31f6 -s0 -A 'udp dst port 514'
```

Файлы появляются после первого сообщения соответствующего процесса.

## Роутер

```text
configure terminal
feature rsyslog
logging remote server 10.121.20.39 7
logging level isis 7
end
```

Нужна доступность сервера с mgmt0 через Cloud. Скрипт не меняет сеть, IP, firewall или роутер. Если firewall активен, отдельно разреши UDP/514 от IP роутера. Не дублируй imudp или приёмник на том же адресе/порту в других файлах rsyslog.

Проверены синтаксис и чтение config.json. Реальный start с очисткой /var/log/remote и перезапуском службы не выполнялся.
